# 🛒 קופה אופליין • Kupa Offline Data Engine
מנוע Python עצמאי לסנכרון, הורדה והשוואת מחירי סופרמרקטים אופליין ישירות ממאגרי **"גרסאות לעם" (over.org.il)**.

---

### ✨ מה המערכת עושה?
1. **חיבור ישיר למאגרים:** מתחבר ל-API של `over.org.il`, בודק אילו רשתות שיווק פעילות (שופרסל, רמי לוי, יוחננוף, ויקטורי, קרפור ועוד) ובודק את תאריך הסריקה האחרון.
2. **הורדה מהירה:** מוריד את קבצי ה-CSV הגולמיים והעדכניים (מוצרים, מחירי סניפים, רשימות סניפים).
3. **מסד נתונים מקומי (SQLite):** מייבא ומאנדקס את כל הנתונים מקומית על המחשב שלך (`kupa_offline.db`).
4. **ביצועים באלפית שנייה (Zero Latency):**
   - חיפוש מוצרים מיידי.
   - השוואת מחירים למוצר בין כל הרשתות והסניפים (כולל סינון לפי עיר).
   - השוואת סל קניות שלם (מקביל לטאב `tab=basket` באתר) – מציאת הסניף הזול ביותר, כמה פריטים קיימים בסל, ומחיר סופי.
5. **שרת מקומי מובנה:** מגיע עם שרת REST API מקומי קליל התואם 1:1 לממשק האפליקציה.

---

### 🚀 איך מפעילים?

#### 1. הפעלת הממשק האינטראקטיבי (CLI):
פתח שורת פקודה בתיקייה זו והרץ:
```bash
python cli.py
```
בממשק תוכל:
* לבדוק מאגרים זמינים.
* להוריד ולסנכרן רשתות למחשב.
* לחפש מוצרים ולהשוות מחירים וסלים ישירות בטרמינל.

#### 2. הפעלת שרת API מקומי:
```bash
python local_api_server.py
```
השרת יעלה בכתובת `http://127.0.0.1:8080`.
* חיפוש מוצרים: `GET /api/prices/table/prices_products?q=חלב`
* השוואת מוצר: `GET /api/prices/compare?item_code=7290000066134&city=ירושלים`
* השוואת סל: `POST /api/prices/basket` עם גוף JSON:
  `{"items": [{"item_code": "7290000066134", "quantity": 1}], "city": "תל אביב"}`

### 📂 מבנה הקבצים:
* `over_api_client.py` – מודול התקשורת מול over.org.il והורדת קבצי ה-CSV.
* `database.py` – ניהול ה-SQLite המקומי, ייבוא נתונים ואינדוקס.
* `offline_kupa_engine.py` – מנוע ההשוואה והחישובים האופליין.
* `sync_manager.py` – מנהל הסנכרון וההורדות.
* `cli.py` – ממשק המשתמש בשורת הפקודה.
* `local_api_server.py` – שרת API מקומי.
* `data_cache/` – תיקיית האחסון המקומית של קבצי ה-CSV.
* `kupa_offline.db` – קובץ מסד הנתונים המקומי המהיר.
